
# Week 8 - Local LLM Inference

## Introduction
This project demonstrates running Large Language Models locally using Ollama.

## Objectives
- Understand local LLM inference.
- Configure Ollama.
- Download Gemma and Llama models.
- Generate responses using Python.
- Compare different prompts and models.
- Perform sentiment analysis and summarization.
- Translate article text.
- Evaluate question-and-answer results.

## Technologies Used
- Python
- Ollama
- Gemma 3 1B
- Llama 3.2 1B
- Jupyter Notebook
- Transformers
- Pandas

## Project Files
- local_llm.py
- article_analysis.py
- notebook/Week8_Local_LLM_Inference.ipynb
- dataset/
- screenshots/

## How to Run
1. Install Ollama.
2. Download the required models.
3. Install Python requirements.
4. Run python local_llm.py.
5. Add a 500–800 word article to dataset/article.txt.
6. Run python article_analysis.py.
7. Open the Jupyter Notebook to view the results.

## Conclusion
This project demonstrates local AI inference, prompt comparison and article analysis.
